# NexusLens: Interactive Data Visualization

**NexusLens** is an interactive, bento-grid style analytics dashboard designed for seamless data exploration and visualization. Vibe-coded using Google AI Studio, this tool provides instant multi-metric views, distributions, and custom charts for any structured dataset.

---

## 📊 Sample Data Repositories

To help you get started immediately, this repository includes two sample datasets that you can upload to test the dashboard's capabilities:

* **Terry's Trousers Data - Website Data.csv** – Ideal for testing e-commerce and website performance metrics.
* **Sales data - Sheet1.csv** – A standard sales dataset perfect for exploring revenue, profit, and unit distributions across regions and channels.

---

## 🚀 Guide: How to Upload and Analyze Data

The dashboard is built to be entirely plug-and-play. You do not need to configure any backend settings or modify files to view your data.

### 1. Accessing the Upload Tool

When you open the NexusLens interface, locate the main welcome banner at the top of the **Bento Dashboard**.

* Click the prominent purple **Upload / Paste Data** button on the right side of the "Active & Ready for Data" card.
* Alternatively, you can use the **Import** button located in the top navigation bar next to the workspace selector.

### 2. Importing Your Dataset

* **Supported Formats:** The visualizer accepts standard CSV or JSON datasets.
* **File Selection:** Browse your local files and select either of the provided sample files (`Terry's Trousers Data - Website Data.csv` or `Sales data - Sheet1.csv`), or choose your own dataset.
* **Instant Processing:** Once uploaded, the dashboard will automatically parse the rows and map your data dimensions.

### 3. Navigating the Data

Once your data is live, use the built-in interface tools to explore your metrics:

* **Filters:** Use the dropdown menus located above the metric cards to filter your data by **Region**, **Category**, **Product**, or **Channel**.
* **Search:** Use the search bar on the left side of the filter row to look up specific records, dimensions, or categories directly.
* **Bento Visualizer Matrix:** Scroll down to the matrix section to view active chart layouts and distributions based on your currently filtered dataset. You can also click **Design New Visual** to create custom views.
